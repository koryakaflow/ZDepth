First release: AI depth maps in EffectCraft.

- **Depth Anything V2** (Small, Base, Large), frame by frame, with Per Clip normalization so the
  map doesn't pump.
- **Video Depth Anything** (Video Small, Video Large): one consistent, flicker-free depth for
  the whole clip.
- **Outputs:** gray depth, Turbo-colored depth, normals, and a depth matte that keeps the layer
  within a depth range.
- Runs on NVIDIA (CUDA); AMD (ROCm) and Apple Silicon (MPS) should work but are untested.
  Linux and macOS; no Windows yet.
- Video Small at Fast fits next to EffectCraft on a 6 GB GPU.

Install or update:

```sh
curl -fsSLO https://github.com/koryakaflow/ZDepth/releases/latest/download/install.sh
sh install.sh
```
